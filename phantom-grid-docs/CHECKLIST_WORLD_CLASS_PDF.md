## 📋 六大核心維度檢驗標準

| 維度編號 | 檢核維度 | 檢驗標準 | 合格條件與斷言 |
| :---: | :--- | :--- | :--- |
| **01** | **網格對齊 (Grid Alignment)** | 8pt / 4pt 基準線網格 | 頁面元素外距、表頭高度、區塊間隔皆為 4pt 或 8pt 整數倍；A4 邊距嚴格符合 `Top/Bottom: 24mm, Inside: 20mm, Outside: 18mm`。 |
| **02** | **數字排版 (Tabular Figures)** | 等寬數字特性（`+tnum`） | 表格內小數點與數值位數縱向絕對對齊；代碼塊與矩陣強制使用 `JetBrains Mono` 等寬字型。 |
| **03** | **圖表標註 (Direct Labeling)** | 末端直接標記與雙重辨識 | 折線圖右側末端直接附帶數列名稱標籤；黑白列印仍可藉由幾何端點符號（● vs ■）與線型（實線 vs 虛線）100% 辨別。 |
| **04** | **字元走勢 (Orphans & Widows)** | 孤行 / 寡行防護 | 跨頁段落結尾保留至少 2 行以上內文；嚴禁單字折行與孤立標點符號。 |
| **05** | **色彩無障礙 (WCAG 2.1 AAA)** | 嚴格對比度標準 | 正文與標題文字對比度 $\ge 4.5:1$（AAA 級）；邊框與輔助圖線對比度 $\ge 3:1$；採用色盲友善調色盤。 |
| **06** | **PDF 數位結構 (Digital PDF)** | Tagged PDF & 互動書籤 | 導出格式符合 PDF/X-4 或 PDF/A 規範；包含 1~3 級書籤目錄（Interactive Bookmarks），點擊秒級跳轉。 |

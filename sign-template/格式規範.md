# 簽呈格式規範

> 從 `中控議決簽呈20260330.xls` 提取的版面與文字規範

## 頁面設定
- **紙張**：A4 橫向（29.7cm × 21.0cm）
- **邊界**：上下 1.0cm、左右 1.5cm

## 字體規範
| 區塊 | 字體 | 字級 | 粗體 |
|------|------|------|------|
| 公司標題 | 新細明體 | 18pt | 是 |
| 「簽呈」標題 | 新細明體 | 20pt | 是 |
| 「單位」欄位 | 新細明體 | 20pt | 是 |
| 主旨/說明內文 | 新細明體 | 11pt | 否 |
| 簽核區表頭 | 新細明體 | 11pt | 否 |

## 版面結構
1. **標題列**：「TGB 台灣金蜂股份有限公司」置中、18pt 粗體
2. **簽呈標題列**：「簽    呈」左側 20pt 粗體 + 「單位」右側 20pt 粗體 + 課別
3. **主旨區**：「主旨:」開頭，11pt
4. **說明區**：「說明:」開頭，11pt，逐項以「一、二、三...」編號
5. **分隔線**：置中「以    上」
6. **呈核示**：左側「呈    核    示」
7. **簽核表格**：6 欄（承辦人→課長→副理→經理→副總經理→總經理）
